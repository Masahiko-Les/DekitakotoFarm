# できたこと農園 サポート

日々の小さな「できたこと」を種にしてドット絵の農園に蒔き、毎日の水やりで振り返るアプリです。

## あそびかた

1. 画面をなぞった方向へキャラクターが歩きます。指を置いたままにすると歩き続けます。
2. 草地や畑の上で A ボタンを押すと、立っている場所に「できたこと」を種として蒔けます。道には蒔けません。
3. 種の上に立って A ボタンを押し、「💧 水やりする」を押すと水をあげられます。水やりは1つの種につき1日1回です。
4. 3回水をあげると花が咲きます。咲いた花は📖思い出帳でいつでも見返せます。

## よくある質問

**Q. 今日はもう水やりできないと表示されます。**
水やりは1つの種につき1日1回です。日付が変わると、また水をあげられます。

**Q. 間違えて植えた種を消したい。**
種の上で A ボタンを押し、「この種を抜く」を2回押すと消せます。咲いた花は消せません。

**Q. 機種変更でデータを引き継ぎたい。**
データはこの端末の中にだけ保存されています。設定（⚙）の「バックアップを保存」でファイルに書き出し、新しい端末で「バックアップから戻す」を選んでください。戻すと、その端末の農園は上書きされます。

**Q. 書いた内容はどこかに送られますか？**
送られません。本アプリは通信を一切行わず、データは端末の中にだけ保存されます。
