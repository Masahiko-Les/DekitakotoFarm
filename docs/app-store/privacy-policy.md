# できたこと農園 プライバシーポリシー

制定日：2026年11月○日

「できたこと農園」（以下「本アプリ」）は、利用者のプライバシーを大切にし、以下のとおり取り扱います。

## 1. 収集する情報

本アプリは、利用者の個人情報やその他の情報を収集しません。

本アプリで入力した文章（「できたこと」）、水やりの記録、キャラクターの位置などは、利用者の端末の中にだけ保存されます。開発者や第三者のサーバーへ送信されることはありません。

## 2. 通信について

本アプリは、インターネットを使った通信を行いません。アカウント登録、広告、アクセス解析、クラッシュレポートの送信なども行いません。

## 3. バックアップについて

設定画面の「バックアップを保存」を使うと、農園のデータをファイル（JSON形式）に書き出し、共有シートから利用者が選んだ保存先（「ファイル」アプリなど）に保存できます。保存先の選択と管理は利用者自身が行います。本アプリがバックアップを外部へ自動で送信することはありません。

## 4. データの削除

設定画面の「すべてのデータを削除」、または本アプリを端末から削除することで、本アプリに保存されたデータはすべて削除されます。

本ポリシーを改定する場合は、このページでお知らせします。
